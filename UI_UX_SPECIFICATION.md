# Design Philosophy

## ❌ Don't Build This

```
---------------------------------------

[Total Cases]

[Hotspots]

[Charts]

```

This is a normal admin panel.

```
═══════════════════════════════════════════════════════════════════════

CrimeLens AI

═══════════════════════════════════════════════════════════════════════
```
